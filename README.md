## 📋 Sobre o Projeto

Portfólio desenvolvido do zero para apresentar minha trajetória, projetos e habilidades como desenvolvedor. O design foi pensado para ser moderno, limpo e com animações de transição suaves, garantindo uma boa experiência em qualquer dispositivo.

**Destaques do design:**
- Paleta escura com acento violeta (`#6C63FF`)
- Tipografia com **Space Grotesk** + **Inter**
- Efeito typewriter no Hero com troca automática de cargo
- Scroll reveal em todas as seções
- Navbar com glassmorphism ao rolar
- Skill bars animadas por Intersection Observer
- Cards de projetos com hover glow e transição suave
- 100% responsivo (mobile-first)

## 🚀 Como rodar localmente

```bash
# Clone o repositório
git clone https://github.com/marcelomrfilho/Marcelo_Filho_Portfolio.git

# Entre na pasta do projeto
cd Marcelo_Filho_Portfolio/portfolio

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
```

Acesse `http://localhost:5173` no navegador.

---

## 📦 Build para produção

```bash
npm run build
```

Os arquivos otimizados serão gerados na pasta `dist/`.
